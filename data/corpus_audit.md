# 1998 年上半年教师带音语料审计

本审计记录当前 n-gram 实验实际使用的语料输入、异常处理、清理计数和文章级切分。可复现输入为仓库内 `data/teacher_1998_jan_jun.rar`；清理与切分代码、固定随机种子及运行命令见仓库根目录的 `README.md` 和 `run_rmrb_experiment.py`。

## 解码异常与冲突记录

按记录逐行严格解码，不使用替换字符。发现 5 条无法按 GB18030 解码的记录；所有异常字节均为十六进制 `AD`。对应文章整篇排除，并在 `results_1-6/experiment_metadata.json` 中保留成员相对行号、行起始偏移、异常字节偏移、记录 ID 和错误原因。

| 文章 ID | 异常记录 ID | 归档成员内异常字节偏移 |
|---|---|---|
| `19980323-09-005` | `19980323-09-005-012` | 4,252,061 |
| `19980430-03-005` | `19980430-03-005-007` | 5,945,346 |
| `19980507-04-007` | `19980507-04-007-005`, `19980507-04-007-011`, `19980507-04-007-013` | 1,025,114; 1,025,580; 1,025,759 |

记录 ID `19980127-09-001-032` 在 1 月成员中出现两个不同正文，成员相对字节偏移为 4,965,857 和 4,966,114。为避免任意选择其中一个版本，整篇文章 `19980127-09-001` 也排除。合计排除 4 篇文章；无记录编号的非空行计数为 0。

| 项目 | 数量 |
|---|---:|
| 物理行 / 空白行 | 143,766 / 20,005 |
| 严格解码后的记录行 | 123,756 |
| 解码异常记录 / 涉及文章 | 5 / 3 |
| 冲突记录编号 / 涉及文章 | 1 / 1 |
| 排除文章（解码异常与正文冲突合并） | 4 |
| 移除读音标注 / `〓` 版式标记 | 95,087 / 10,587 |
| 移除完全重复记录行 / 文章内重复段落 / 重复文章 | 6 / 228 / 46 |
| 最终记录 / 文章 / 词面 token | 123,386 / 18,581 / 7,293,878 |

完全重复的段落和文章在切分前去除；文章 ID 在训练集和测试集之间不交叉。随机种子为 `20260929`，目标训练比例为 80%。

| 切分 | 文章数 | 记录数 | 词面 token 数 |
|---|---:|---:|---:|
| 训练集 | 14,802 | 98,722 | 5,797,582 |
| 测试集 | 3,779 | 24,664 | 1,496,296 |

词表只从训练数据生成，含 `__UNK_TOKEN__` 共 69,864 项；测试集 29,585 个 OOV token 映射到该符号。验证报告确认训练与测试文章重合数为 0。清理语料、文章索引、KenLM 输入、测试评分输入和训练词表分别归档于 `results_1-6/data/`。完整统计与异常位置见 `results_1-6/experiment_metadata.json`，独立校验与模型复评分数见 `results_1-6/validation.json`。

此前的 n-gram 实验使用过不同来源及文本表示的 PFR 语料；本次只使用上述教师归档。两次语料、分词表示和切分不相同，PPL 不作为同条件的前后改进比较。当前实验仓库为 <https://github.com/stq1234/LLMandAppliedPractices-n-gram-programming>。
